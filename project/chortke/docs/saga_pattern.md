## الگوی Saga — مستندات و راهنمای پیاده‌سازی

هدف این سند: توضیح مختصر، نمونه‌واری از `SagaOrchestrator` موجود، و چک‌لیست اقدامات برای ریفکتور و تست.

1) خلاصه
- پیاده‌سازی فعلی: `app/Services/SagaOrchestrator.php` یک اورکستراتور ساده اما کاربردی است که مراحل را ثبت و در صورت خطا کامپنسیشن‌ها را به ترتیب معکوس اجرا می‌کند.

2) وقتی از Saga استفاده کنیم
- هنگام انجام تراکنش‌های توزیع‌شده که نمی‌توانند به‌راحتی با یک تراکنش DB پوشش داده شوند (مثلاً نگه‌داشتن پول + ایجاد رکورد خارجی + فراخوانی سرویس دیگر).

3) نمونه‌ی استفاده (خلاصه)
- مشاهده در `app/Services/FinancialEscrowService::holdSocialTaskFunds` که چندین مرحله را با `addStep` تعریف می‌کند و سپس `execute()` می‌زند.

4) نکات ایمنی و پیشنهادها
- حتماً برای هر مرحله، سناریوی جبرانی تعریف شود.
- مراحل فقط باید کار لازم را انجام دهند و از side-effectهای نامشخص بپرهیزند.
- لاگ‌گذاری کافی برای هر قدم (`info`, `warning`, `critical`) ضروری است.

5) تست‌ها
- ایجاد تست‌های واحد که موارد موفق و شکست را پوشش دهند. تست باید رفتار اجرای جبران‌ها را تایید کند.

6) چک‌لیست ریفکتور فاز ۱
- [ ] افزودن تست‌های واحد برای `SagaOrchestrator` (موفق/ناموفق و ترتیب کامپنسیشن)
- [ ] مستندسازی نمونه‌ها (این فایل)
- [ ] اضافه کردن مثال در `docs/` و لینک در PR checklist

جزئیات بیشتر: در صورت نیاز می‌توانیم نمونه PR با تست‌ها و CI run آماده کنیم.
