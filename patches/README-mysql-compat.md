# سازگاری با MySQL — پچ MigrationService

## مسئله
مهاجرت‌های پروژه از نحو اختصاصی MariaDB استفاده می‌کنند که MySQL آن را با
خطای 1064 رد می‌کند:

| الگو | تعداد |
|---|---|
| `ALTER TABLE ... ADD [COLUMN] IF NOT EXISTS` | ۹۴۲ |
| `ADD [UNIQUE] INDEX\|KEY IF NOT EXISTS` | ۷ |
| `DROP INDEX IF EXISTS` | ۲ |
| `DROP FOREIGN KEY IF EXISTS` | ۱ |

مجموعاً ۹۵۲ دستور در ۶۴ فایل از ۱۴۲ فایل SQL.

## راه‌حل انتخاب‌شده: اصلاح در Runner (۱ فایل) نه در SQL (۶۴ فایل)

`app/Services/MigrationService.php` — دو متد جدید:

- `isMysqlServer()` — با `PDO::ATTR_SERVER_VERSION` تشخیص می‌دهد سرور
  MySQL است یا MariaDB (رشته‌ی «MariaDB» در نسخه). نتیجه memoise می‌شود.
- `rewriteForMysql()` — فقط وقتی سرور MySQL باشد فراخوانی می‌شود:
  1. عبارت `IF [NOT] EXISTS` را از بندهای ALTER حذف می‌کند.
  2. ALTER چندبندی را به چند دستور تک‌بندی می‌شکند.

### چرا حذف عبارت شرطی امن است؟
Runner از قبل خطاهای ۱۰۵۰/۱۰۶۰/۱۰۶۱/۱۰۹۱/۱۸۲۶ («از قبل وجود دارد» /
«وجود ندارد») را idempotent تلقی و رد می‌کند
(`isIdempotentSqlError`). پس همان محافظتی که `IF NOT EXISTS` می‌داد،
از قبل در لایه‌ی خطا موجود است.

### چرا شکستن ALTER چندبندی لازم است؟
MySQL بندهای یک ALTER را اتمیک اعمال می‌کند. اگر فقط یک بند تکراری باشد،
کل دستور — شامل بندهایی که باید اجرا می‌شدند — لغو می‌شود. در MariaDB
هر بند `IF NOT EXISTS` مستقل ارزیابی می‌شود. شکستن به دستورهای مجزا
همان رفتار «هر بند مستقل» را بازتولید می‌کند.

پارسر بندها کامای سطح‌بالا را از کامای داخل `ENUM('a','b')`،
`DECIMAL(10,2)`، لیست ستون‌های ایندکس و رشته‌های نقل‌قولی تفکیک می‌کند.

## سازگاری با MariaDB — بدون تغییر رفتار
روی MariaDB `isMysqlServer()` مقدار `false` برمی‌گرداند و مسیر بازنویسی
اصلاً اجرا نمی‌شود؛ SQL دقیقاً مثل قبل و بومی اجرا می‌شود.

## اعتبارسنجی
- ۱۴ تست واحدِ هدفمند (حذف شرط، شکستن چندبندی، کامای داخل پرانتز/رشته،
  دست‌نزدن به `CREATE TABLE IF NOT EXISTS` و `DROP TABLE IF EXISTS`
  که در MySQL معتبرند) — ۱۴/۱۴ قبول.
- اجرا روی **۱۲۶۸ دستور واقعی** پروژه: ۳۸۸ بازنویسی (۹۷ مورد شکسته به
  چند دستور)، **صفر** ناسازگاری باقی‌مانده، پرانتز و بک‌تیک همه متوازن.
- روی MariaDB واقعی: ۱۴۸ مهاجرت اجرا، ۲۶۱ جدول، اجرای دوباره تمیز.
- تست‌های موجود MigrationService: ۵۲/۵۲ سبز.
